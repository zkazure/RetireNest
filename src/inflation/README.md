# inflation：名义金额与实际购买力

## 口径

- 名义转实际：`实际 = 名义 / (1 + 年通胀率)^年数`。
- 实际转名义：`名义 = 实际 × (1 + 年通胀率)^年数`。
- `cumulative_factor` 是名义金额与实际金额的比值，与换算方向无关。

## 边界

- 只做一次性幂运算，不建模逐年变化的通胀，也不含 CPI 分项。
- `savings.*` 与 `simulation.*` 已经按实际购买力计算；不要再拿本工具折算它们的输出，否则会重复扣通胀。
- 金额用 float，输出 `number`；`pension.basic` 的 Decimal 口径是精算金额，不与这里混用。
