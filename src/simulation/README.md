# simulation：蒙特卡洛与安全提取率

## 模型

- 名义毛收益率取对数正态，均值为 `1 + 名义年回报率`，标准差为输入的 `volatility_pct`。
- 通胀按输入确定性折算，实际毛收益率 = 名义毛收益率 / `(1 + 通胀率)`。
- 积累期每年年末投入 12 个月合计；退休期每年年末支取 `max(年支出 - 年养老金, 0)`。
- 余额为负即视为耗尽；`success_rate` 是未耗尽路径的占比，不是概率保证。

## 可复现

`random.Random(seed)` 生成路径。相同参数与相同 seed 必然得到相同结果，因此命令的
`deterministic` 仍为 `true`；这里的“确定性”指可复现，不是没有随机性。

## 文件

- `returns.py`：对数正态参数、单次抽样、`generate_real_paths`。
- `monte_carlo.py`：`simulate()`，输出成功率、期末余额分位、耗尽年份分位、逐年余额分位。
- `withdrawal.py`：`safe_withdrawal()`，在目标成功率下二分搜索最高提取比例。
- `statistics.py`：线性插值分位数。

## 性能

默认 2000 条路径、约 40 年，约 8 万步；安全提取率再做 24 次二分，约 150 万步。
纯 Python 下默认参数通常不到 1 秒。路径数上限 20000，避免单次请求过慢。

## 不做

- 不做名义收益与通胀双随机；通胀不确定性请体现在更高的波动率输入里。
- 不做税费、手续费、资产配置差异、收益率序列自相关。
- 不把安全提取率包装成“保证收益”或“4% 法则一定安全”。
