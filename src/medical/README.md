# Medical

只输入年龄、居住城市、医保类型，返回当前年龄段的年度和月均医疗消费预算。
这是一版使用演示调整系数的功能原型，不预测退休年龄或未来年份的价格。

## 使用

在 `src/` 下执行：

```text
uv sync --locked
uv run python -m medical
```

程序依次询问年龄、城市和医保类型。运行固定示例：

```text
uv run python -m medical --demo
```

Python 调用：

```python
from medical import estimate_medical_cost

result = estimate_medical_cost(age=35, city="上海", insurance="职工医保")
# age_group: 18–39岁
# annual_medical_cost: 1976.06 元/年
# monthly_medical_cost: 164.67 元/月
# note: 演示估算及参数未校准的说明
```

年龄为 0–120 岁整数；医保类型支持职工医保、居民医保、无医保及部分常用别名。
城市接受上海或上海市这样的名称；未配置城市使用全国地区系数并在说明中提示。
参数错误抛出 `ValueError`。`estimate_medical_costs` 是同一函数的别名。

## 数据与假设

全国参考值为国家统计局公布的 2025 年全国居民人均医疗保健消费支出 2573 元。
来源：[2025年居民收入和消费支出情况](https://www.stats.gov.cn/sj/zxfb/202601/t20260119_1962321.html)，核对日期 2026-11-02。
其口径是居民医疗保健消费，不是医保报销前的临床医疗总费用，也不是某一年龄段的官方标准。

年度预算 = 全国参考值 × 年龄系数 × 地区系数 × 医保调整系数。
月均预算 = 年度预算 / 12。结果保留两位小数，按 2025 年参考价格表示。

下面的系数全部是可替换的演示假设，尚未经过统计校准：

- 年龄：0–17 岁 0.6；18–39 岁 0.8；40–59 岁 1.1；60–74 岁 1.8；75 岁及以上 2.5。
- 地区：北京、上海、广州、深圳 1.2；其他城市暂用 1.0。
- 医保：职工医保 0.8；居民医保 1.0；无医保 1.5。

这些系数不是官方系数或真实报销比例，不表示各地区或医保人群实际具有该支出差异。
医保系数只是相对消费参考值的演示调整，不能再当作报销比例扣一次。
年龄系数没有按人口结构加权校准，不保证还原全国平均值。
参数集中放在 `costs.py`，后续可在不增加用户输入的情况下替换。

当前可验收接口、分组、输入检查和功能演示。金额准确性尚未验证，不能据此确定真实退休资金。
本版不单独计算保险缴费、长期护理、重大疾病或未来通胀。

## 三态支出

`tri_state.py` 把医疗支出拆成无病无灾、小病小灾、大病大灾三档，供 `lifecycle`
做年度仿真：

- 三态概率按年龄段给，分性别调整；小病概率对齐年住院率约 22%，大病概率是
  `[待转录]` 的临时值，等重疾表 CI4 到位后整表替换，只改这一个文件
- 成本 = 基线门诊 1200 元 + 事件附加；小病附加 12000（次均住院 9870 上浮），
  大病附加 15 万（治疗、护理与收入损失）
- 期望年支出 = Σ 概率 × 各态年支出，`expected_annual(age, sex)` 直接可用

替换数据时的约束：三态概率之和必须为 1，且 `major < minor`，否则
`TriStateProbability` 在校验阶段就会拒绝。
