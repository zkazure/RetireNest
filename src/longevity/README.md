# longevity：Gompertz 寿命估计

## 模型

生存函数从出生起算：

```
S(x) = exp(-exp((x - m) / b) + exp(-m / b))
```

- `b` 是离散参数，默认 9.5 年。
- 给定出生时预期寿命后，用数值积分（梯形，步长 0.1 年）与二分校准 `m`。
- 结果条件于当前年龄：`P(T > x | T > age) = S(x) / S(age)`。
- 分位数由反函数求解，并截断在 120 岁。

## 参数

`params.py` 中的基准预期寿命、`b` 和健康档位平移都是演示假设，`as_of=2020`。它们取整自公开报道的全国人均预期寿命，不是生命表，也没有按地区、城乡、教育、收入或个体病史校准。真实产品必须换成有来源的生命表并单独评审。

## 输出

死亡年龄的 p10/p25/中位/p75/p90、活到 85/90/95 岁的条件概率、中位剩余寿命。
领域函数里的概率是 0–1 的比例；`longevity.estimate` 命令层把它乘以 100，输出百分数。

## 不做

- 不做医学预测、疾病史建模、吸烟/体检指标等个体因素。
- 不做地区生命表、队列效应或死亡率改善趋势。
- 不把中位数当作唯一规划终点；需要时可以取 p75 或 p90 做保守规划。
