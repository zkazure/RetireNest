# Profit

目前只计算一项被动收入：银行活期存款收益。养老金等其他收入暂不在本模块范围内。

## 计算口径

按单利一次性计息：

```
日利率   = 年利率 ÷ 360
利息     = 本金 × 日利率 × 实际天数
期末本息 = 本金 + 利息
```

- 360 天折算：人民银行规定人民币业务的日利率按年利率除以 360 折算，不是 365。
- 实际天数：算头不算尾，即天数 = 结束日期 − 起始日期。
- 精度：本金、利率、利息全程用 Decimal；利息四舍五入保留到分，利率不做取整。

## 参数

- 本金：单位为元，须大于 0。
- 年利率：默认 0.05%。该值取自 2025 年 5 月六大行活期挂牌利率，此后仍在下调，2026 年部分农商行活期已降至 0.01%，因此利率由调用方传入，默认值只作缺省，不写死在计算里。
- 起止日期：用于计算实际天数。

## 示例

本金 100000 元、年利率 0.05%、存 365 天：

```
利息     = 100000 × 0.0005 ÷ 360 × 365 = 50.69 元
期末本息 = 100050.69 元
```

## 代码用法

```python
from datetime import date

from profit import DemandDeposit, calculate

deposit = DemandDeposit(
    principal="100000",  # Decimal、int 或字符串；float 会被拒绝
    annual_rate="0.0005",  # 省略则用默认的 0.05%
    start_date=date(2026, 1, 1),
    end_date=date(2027, 1, 1),
)
result = calculate(deposit)

result.days  # 365
result.interest  # Decimal('50.69')
result.total  # Decimal('100050.69')
result.daily_rate  # Decimal('0.0000013889')，仅供展示，不参与计算
```

金额一律用 Decimal，不要用 float；本金最多两位小数，超过直接报错。参数不合法时抛 `ProfitError`（`ValueError` 的子类），消息里写明是哪个参数、期望什么。


## 已知取舍

- 不复利：真实活期按季结息、利息并入本金，季度复利一年只差几毛钱，本期按单利处理；若要和银行对账单逐笔对齐，再改为按季结息。
- 利率单一：不建模持有期内的利率变化，跨降息周期由调用方分段计算后相加。
- 单一账户：不支持多账户分别计算与汇总。
