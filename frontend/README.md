# RetireNest 前端

HTML + CSS + 原生 TypeScript，使用 Vite 开发和构建，不依赖 UI 框架或外部字体。

## 启动

在 frontend 目录执行：

```powershell
npm install
npm run dev
```

浏览器打开终端中显示的本地地址（默认 http://127.0.0.1:5173）。

```powershell
npm run build
npm run preview
```

build 同时执行 TypeScript 严格检查和生产构建，静态产物位于 dist/。

## 当前功能

- 基本信息、收支、资产负债、退休目标、回报及通胀假设表单。
- 退休资金目标、预计资产、资金缺口、准备度和月结余目标。
- SVG 资产曲线、退休节点、目标线、资产不足年龄。
- 保守 / 基准 / 乐观情景，名义回报分别为用户输入 −1 / 不变 / +1 个百分点，限制在输入范围内。
- 输入校验、测算说明弹窗、PDF 报告导出。
- 桌面 / 平板 / 手机响应式布局。

启动时播放可跳过的 slogan 动画，开启系统减少动画偏好时直接进入。页首保留品牌，仅在结果页显示导出按钮，初始仅展示填写卡片。选择“其他”城市时需填写城市名称。点击“生成我的退休规划”且校验成功后，隐藏填写卡片，展示约 1.8 秒的三阶段过渡动画，随后淡出 400 毫秒，再展示结果；点击“返回修改”或“调整我的规划”可返回，填写内容保留。生成前、生成过程中和返回编辑时隐藏导出按钮，避免导出未确认的草稿。切换情景卡片只更新该情景说明，不替换基准图表。内容不在浏览器持久化，刷新后恢复示例，不上传个人信息。

## 与后端对接

- src/model.ts：PlanInput、PlanResult、校验和演示计算。未来由计算 API 返回 PlanResult。
- src/main.ts：页面、表单事件和渲染。目前 renderResults 内调用 calculatePlan；对接时把结果作为参数传入，提交时 fetch 后端，并补充加载和错误状态。
- src/style.css：视觉样式、布局和响应式规则。

PlanInput 金额单位是元；nominalReturn 和 inflation 是百分数（3 表示 3%）；coverage 也是百分数（80 表示 80%）。points[].assets、target、projected 和 gap 的单位均为元。depletedAge 为首次在退休期出现负资产的年龄，未出现则为 null。

AI 目前未接入。底部“规则解读”由本地条件生成，之后可替换为后端 LLM 的结果；不要把模型密钥放进前端。

## 演示计算口径

全部金额用今天的购买力表示。实际回报率 = (1 + 名义回报率) / (1 + 通胀率) − 1。假设工资、支出和养老金随通胀同步变化，实际金额保持不变。

当前净资产 = 总资产 − 总负债；月结余 = 收入 − 支出。工作期每年年末计入 12 个月结余；退休后每年年末支取 max(退休月支出 − 月养老金, 0) × 12。养老金视为退休起持续领取的用户假设。

目标资金为退休后各年净支出的现值；预计资产为当前净资产和未来结余在退休时的累积值。负债直接抵减资产，不另算利息；不计税费、回报波动、社保政策。城市只展示，不影响计算。负资产会在图上继续呈现，用于暴露缺口。

结果仅供比赛演示和学习，不是投资建议或真实养老金测算。





## API 输入与提示动画

生成按钮上方新增可选 API Key 遮罩输入栏，目前仅为界面预留，未发送或调用任何 API。输入不进入 PlanInput、规划导出文件或浏览器持久存储。删除了载入示例按钮，表单保留初始演示值。

提示栏以 350ms 从底部升入，显示约 3.2 秒后以 300ms 淡出。连续提示会取消旧的退出定时器。减少动画偏好下直接切换。



## PDF 报告导出

结果页点击“导出规划”直接下载两页 A4 PDF，内容包括规划概览、输入信息、资产曲线、三种情景、规则解读及测算假设。使用已生成结果对应的数据，不读取正在编辑的草稿。导出期间按钮禁用并显示生成状态，失败可重试。

实现位于 src/pdf-export.ts，pdf-lib 通过动态导入按需加载。中文使用浏览器本机字体在 2 倍分辨率 Canvas 绘制，再嵌入 PDF；报告是图像页面，文本暂不支持选择、搜索。导出不上传数据、不包含 API Key。

## 动态表单模板

填写栏已改为配置驱动。新增同类字段只需编辑 src/form-template.json，通用渲染器会自动展示并收集数据。生活偏好可折叠，医保、养老金和存款信息按需启用；隐藏字段不提交，decimal 保留字符串精度。

给后端的协议、字段扩展方法与序列化规则见 [FORM_TEMPLATE.md](FORM_TEMPLATE.md)，请求/响应示例见 contracts/。当前后端尚未对接，新增模块只收集信息；基础结果和 PDF 继续使用本地演示计算。

执行 npm test 验证模板与数据收集逻辑。
