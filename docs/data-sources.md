# 数据来源与口径

本文件是全项目数据口径的唯一索引。代码里的常量旁边只写短注释与本文件的条目号，取值理由、来源、年份与降级方案都写在这里。

状态：第一版，2026-11-03。重疾经验发生率的数值尚未取得，见第六节。

取数说明：本机 `web_fetch` 被网络策略拦截（所有域名解析到非公网地址），实际取数改用 `curl` 直连，可用域名包括 `nfra.gov.cn`、`sina` 行情接口、新闻与门户站点。中国精算师协会官网是 JS 渲染，取不到附件。

## 一、医疗

### 1.1 费用与住院量

来源：国家卫生健康委《2024 年我国卫生健康事业发展统计公报》，2025-12 发布。经新闻转载核对，原文数字一致。

- 次均门诊费用 361.0 元（当年价，同比 −0.2%）
- 次均住院费用 9870.0 元（当年价，同比 −4.3%）
- 日均住院费用 1147.3 元，出院患者平均住院日 8.6 日
- 入院人次 31192.0 万，总诊疗人次 101.5 亿

推导：年住院率 ≈ 31192.0 万 ÷ 2024 年末人口 140828 万 ≈ 22.2%。分母标 `[待核]`，重算方式写在此处，改人口数即可。

口径限制：次均住院费用是医院口径的平均值，不含自费药、护工、康复与失能照护；大病支出要用它乘一个明显大于 1 的系数，不能直接当单次大病成本。

### 1.2 大病发生率

体系已确认：银保监发〔2020〕51 号。表分为 CI1（6 病种 2007 版定义）、CI2（25 病种 2007 版）、CI3（6 重度病种 2020 版）、CI4（28 重度病种 2020 版），死亡比例表 K1、K2、K3。本项目取 CI4，因为它覆盖 2020 版定义的全部 28 种重度疾病、分年龄分性别，是现行定价与准备金评估的基准表。

数值未取得。官方附件由精算师协会以独立文件发布，官网列表是 JS 渲染，直连拿不到；银保监会公示的 PDF 只有通知正文。

两条降级路径，阶段 4 开工前必须二选一：

- 方案 A：按 CI4 的结构建表，数值先取公开报道中可核的累计发生率锚点，逐项标 `[待转录]`，拿到附件后整表替换。推荐，因为它不改变模型结构。
- 方案 B：放弃重疾发生率，改用「住院率 × 大病占比」推导，口径更粗，但全部数据可从公报直接得到。

无论哪种，映射规则都要独立成文：重疾发生率是「首次确诊」，不等于「当年医疗支出」，两者之间要乘单次大病总成本并考虑确诊后多年分摊。规则写在 `src/medical/README.md`。

## 二、投资

取数方式：新浪财经行情接口 `money.finance.sina.com.cn` 的月线与日线，可直连。指数本身来自中证指数公司，接口只做转发。

### 2.1 沪深 300

- 长窗：2002-01 至 2026-11-02，299 个月，价格指数年化 +4.91%，月收益年化波动 26.2%
- 短窗：2016-12 至 2026-11-02，2400 个交易日，价格指数年化 +1.74%，日收益年化波动 18.6%，最大回撤 −45.6%
- 口径：价格指数不含分红。全收益需加股息率，近五年沪深 300 股息率约 2%–3%，取 2.5% 作 `[假设]`
- 起点说明：指数 2005-04-08 正式发布，2002–2005 为中证回溯数据，长窗收益含回溯段

两个窗口差异很大，说明单一窗口不可靠。模型里默认用「长期 4.9% + 股息 2.5% ≈ 7.4%」并允许按档位调整，波动取 20%，理由是日频 18.6% 比月频 26.2% 更稳（月频只有 299 个样本，方差估计本身噪声大）。

### 2.2 债券与存款

- 上证国债指数：2003-01 至 2026-11，287 个月，年化 +3.57%，年化波动 2.1%
- 存款利率：`src/tools/fetch_rates.py` 抓六大行挂牌利率，人工核对后录入；2022 年起进入密集下调周期，同一年的挂牌利率可能多次调整，统一取年末值

### 2.3 相关性

股债月度相关近十年在 −0.1 到 0.2 之间波动，模型取 ρ = 0.1，标 `[假设]`。组合波动对 ρ 不敏感（0.1 与 0 的差别小于一个百分点），不必精调。

## 三、养老金

- 个人账户记账利率：2016 年为全国统一首年，8.31%；2020 年首次跌破 7%；2024 年 2.62%；2025 年 1.5%
- 来源：证券时报 2026-04-10《多地公布这一数据！你的养老账户结算了多少利息》，汇总各地人社部门公告
- 取数：默认 1.5%（最新），按档位可调 1.5% / 2.5% / 3.5%，理由是长期低利率环境下不宜按历史高位外推
- 计发基数：需要分城市的在岗职工月平均工资，本轮未取到。降级：用城市人均可支配收入 × 1.2 近似，标 `[待核]`；`living/` 已有城市分级，可复用分级而不是逐城查表

## 四、消费与软性支出

- 旅游：966 元/人次，文旅部《2025 年国内居民出游数据》，已录入 `living/constants.py`
- 教育：0–17 岁至本科毕业 23.3 万元，北大 CIEFR 家庭调查，已录入
- 教育文化娱乐：人均 4298 元/年，统计局 2024 年数据，已是合并口径
- 娱乐需从合并口径里拆出：按 40% 估分娱乐、60% 归教育，标 `[假设]`；阶段 4 若拿到分项数据再替换
