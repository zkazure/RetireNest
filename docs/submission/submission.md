# RetireNest 作品提交物料

本目录是黑客松作品提交页的填表物料。文案可直接粘贴到表单，图片直接上传。

- `submission.md`：标题、简介、分类、三个相关链接
- `cover.png`：1280×720，广场卡片用（对应表单「封面」）
- `poster.png`：1080×1920，详情页竖版用（对应表单「作品海报」，9:16 PNG）
- `cover.html` / `poster.html`：两张图的版式源文件
- `build-images.py`：把 HTML 渲染成 PNG，并校验尺寸与体积

## 一、标题（上限 40 字）

采用：

> 退有所算：把退休焦虑换成一张可复核的现金流表

共 22 字。备选两个，评委偏好技术路线时可换：

1. 退有所算：算清退休要存多少钱，再给出可执行方案（23 字）
2. 退有所算 RetireNest：确定性引擎算口径，AI 只负责提问（33 字）

## 二、简介（上限 600 字）

> 大多数人算退休，只能凭感觉焦虑。退有所算把这件事变成一张逐年可核对的现金流表：填入城市、年龄、收入、资产、负债、期望退休年龄与生活水平，就能得到退休所需存款、当下缺口和建议储蓄率；再把三档资产配置放进蒙特卡洛，算出成功率、破产年龄分位，以及「维持现有支出需要多少收入」。
>
> 关键数字不交给模型猜。测算全部跑在确定性引擎上：收入按工资、养老金、资产收益三段堆叠，养老金按实际退休年龄取计发月数，终值拆成「退休时资产 + 累计投入 + 累计投资收益」，逐分对平。大模型只负责对话收集参数、解释结果，每个数字都能回溯到数据来源与年份。
>
> 已经做完的部分：表单以选择题为主，示例画像「奶龙」一键填充；五个视图（支出结构、收入曲线、收支对比、风险与生活分布、策略对比）配两页 PDF 报告；五个策略预设（安然一生、丁克、早退 FIRE、养娃一孩、低耗稳健）并排对比；六个计算原语可独立调用复核。奶龙画像的结果是养老金 14,305 元/月、退休时资产 667.7 万、84 岁终值 1235.2 万，终值正好等于投入加收益。后端 556 条测试通过、3 条跳过。

字数见文末统计，粘贴前不用再数。

## 四、相关链接（三个均为必填，须为 HTTP/HTTPS 地址）

表单要求三条链接齐全，建议按「源码 → 可点开的演示 → 看得到的录像」来分工。

1. 代码仓库
   `https://github.com/<你的账号>/RetireNest`

   建议设为公开仓库。README 已写清一键运行方式（`make dev`）、数据口径文档与命令协议，评委不必问就能自证。

2. 在线演示
   `https://<你的域名>/`

   必须是公网可访问地址，`127.0.0.1` 与 `localhost` 一律不行。部署用单端口演示模式：

   ```bash
   uv run --project src python run.py --prod --no-open
   ```

   由 FastAPI 在 8000 端口同时托管页面与 API，反代到域名即可。演示环境没有公网模型密钥时，设 `RETIRENEST_AGENT_FAKE=1` 让右下角对话给出固定演示，命令与页面不受影响。

3. 演示视频
   `https://www.bilibili.com/video/<BV 号>`

   两到三分钟够用，按四步走：示例画像「奶龙」一键填充、五个视图切换、五个策略并排对比、两页 PDF 报告导出。这条最能替评委省时间，值得单独录。
